# GALIO STL — Yolluk & Boylama

Tarayıcıda çalışan, atölye için STL/3DM düzenleme aracı:
- Fırçayla yüzey silme
- Ayarlı çapta yolluk / destek çubuğu ekleme
- Yüzük boylama (taşları bozmadan, boy boy STL / toplu ZIP)
- .3dm → STL çevirme
- Render (PNG) alma

GitHub Pages ile yayında. Masaüstüne kurmak için: Chrome'da sayfayı aç → adres çubuğundaki **Kur** simgesine bas. Kendi penceresinde, program gibi açılır; ilk açılıştan sonra çevrimdışı da çalışır.

Kod güncellendikçe uygulama otomatik yenilenir.
